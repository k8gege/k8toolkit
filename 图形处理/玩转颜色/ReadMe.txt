软件名称：玩转颜色(PlayColor)
最新版本：5.0正式版
文件大小：150K
软件性质：免费软件
开发组员：3L工作室(版权所有)
使用平台：Win9X/Me/NT4.0/2k/XP (Win95需要VB5运行库)
３Ｌ主页：http://3LSoft.y365.com
软件简介：玩转颜色是个免费的颜色软件。拥有友好的界面和小巧的身躯，可以获取屏幕上的任何颜色，以RGB，网页，16进制，色素代码，Delphi颜色输出。更可以输入颜色代码调配颜色；自带颜色收藏夹。更可以获取网页中的配色方案，保存起来。适用于编程，网页制作等。
