File 对象		  语言参考

请参阅                   属性                   方法

描述
提供对文件的所有属性的访问。
说明

以下代码举例说明如何获得一个 File 对象并查看它的属性： 

Sub ShowFileInfo(filespec)
    Dim fs, f, s
    Set fs = CreateObject("Scripting.FileSystemObject")
    Set f = fs.GetFile(filespec)
    s = f.DateCreated
    MsgBox s
End Sub
