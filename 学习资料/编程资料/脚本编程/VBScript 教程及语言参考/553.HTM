SubFolders 属性		 语言参考
版本 3

请参阅                   应用于

描述
返回由指定文件夹中所有子文件夹（包括隐藏文件夹和系统文件夹）组成的 Folders 集合。
语法
object.SubFolders

object 应为 Folder 对象的名称。

说明
以下代码举例说明如何使用 SubFolders 属性： 
Sub ShowFolderList(folderspec)
    Dim fs, f, f1, s, sf
    Set fs = CreateObject("Scripting.FileSystemObject")
    Set f = fs.GetFolder(folderspec)
    Set sf = f.SubFolders
    For Each f1 in sf
        s = s & f1.name 
        s = s &  vbCrLf
    Next
    MsgBox s
End Sub
