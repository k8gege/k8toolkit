Delete 方法		 语言参考
版本 3

请参阅                   应用于

描述
删除指定的文件或文件夹。
语法
object.Delete force

Delete 方法的语法有以下部分：

部分 描述
object 必选。应为 File 或 Folder 对象的名称。
force 可选。Boolean 值。如果要删除的文件或文件夹的属性设置为只读属性，则该值为 True；否则为 False（默认）。

说明
如果指定文件或文件夹不存在，则会出现错误。

对 File 或 Folder 应用 Delete 方法的结果与使用 FileSystemObject.DeleteFile 或 FileSystemObject.DeleteFolder 执行的操作完全相同。

Delete 方法无法区分文件夹中是否包含内容。无论指定的文件夹中是否包含内容，都将删除该文件夹。
