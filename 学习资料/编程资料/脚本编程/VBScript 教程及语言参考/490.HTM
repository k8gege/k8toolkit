Files 属性		  语言参考  
版本 3  

请参阅                   应用于

描述
返回由指定文件夹中所有 File 对象（包括隐藏文件和系统文件）组成的 Files 集合。
语法
object.Files

object 应为 Folder 对象的名称。

说明
以下代码举例说明如何使用 Files 属性： 
Sub ShowFileList(folderspec)
    Dim fs, f, f1, fc, s
    Set fs = CreateObject("Scripting.FileSystemObject")
    Set f = fs.GetFolder(folderspec)
    Set fc = f.Files
    For Each f1 in fc
        s = s & f1.name 
        s = s &  vbCrLf
    Next
    MsgBox s
End Sub
