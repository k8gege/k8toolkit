描述
用于对表达式执行逻辑非运算。
语法
result = Not expression

Not 运算符的语法有以下部分：

部分 描述
result 任意数值变量。
expression 任意表达式。

说明
下表显示如何确定 result 的值：

如果 expression 为 则 result 为
True False
False True
Null Null

0 1
1 0
