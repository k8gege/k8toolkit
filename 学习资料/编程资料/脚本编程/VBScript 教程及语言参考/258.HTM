Clear 方法 		语言参考
版本 1

请参阅                    应用于

描述
清除 Err 对象的所有属性设置。
语法
object.Clear

object 应为 Err 对象的名称。

说明
在错误处理后，使用 Clear 显式地清除 Err 对象。此操作是必须的，例如使用 On Error Resume Next 延迟错误处理时。在任何时候执行下列语句，VBScript 自动调用 Clear 方法：
  • On Error Resume Next
  • Exit Sub
  • Exit Function
