Folder 对象		  语言参考
版本 3

请参阅                   属性                   方法

描述
提供对文件夹所有属性的访问。
说明
以下代码举例说明如何获得 Folder 对象并查看它的属性： 
Sub ShowFolderInfo(folderspec)
    Dim fs, f, s,
    Set fs = CreateObject("Scripting.FileSystemObject")
    Set f = fs.GetFolder(folderspec)
    s = f.DateCreated
    MsgBox s
End Sub
