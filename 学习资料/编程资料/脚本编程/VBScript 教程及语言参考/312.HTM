GetExtensionName 方法		 语言参考
版本 3

请参阅                   应用于

描述
返回字符串，该字符串包含路径最后一个组成部分的扩展名。
语法
object.GetExtensionName(path)

GetExtensionName 方法的语法有以下部分：

部分 描述
object 必选。应为 FileSystemObject 的名称。
path 必选。指定路径，用于返回其组成部分的扩展名。

说明
对于网络驱动器，根目录 (\) 也认为是一个组成部分。

如果路径组成部分与 path 参数不匹配，则 GetExtensionName 方法返回零长度字符串 ("")。
