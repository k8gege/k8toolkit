RemoveAll 方法 		语言参考
版本 2

请参阅                   应用于

描述
RemoveAll 方法删除 Dictionary 对象中的所有键和项目对。
语法
object.RemoveAll

object 应为 Dictionary 对象的名称。

说明
下列代码举例说明如何使用 RemoveAll 方法： 
Dim a,d,i             '创建一些变量
Set d = CreateObject("Scripting.Dictionary")
d.Add "a","Athens"     '添加键和项目
d.Add "b","Belgrade"
d.Add "c","Cairo"
...
a = d.RemoveAll         '清除 dictionary
