描述
现有路径后附加名称。
语法
object.BuildPath(path, name)

BuildPath 方法的语法有以下部分：

部分 描述
object 必选。应为 FileSystemObject 对象的名称。
path 必选。要附加 name 的现有路径。可以是绝对或相对路径且无需指定现有文件夹。
name 必选。要附加到现有 path 的名称。

说明
仅在必要时，BuildPath 方法在现有路径与该名称之间插入附加路径分隔符。
